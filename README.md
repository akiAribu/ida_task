
# TMDB: Анализ успешности фильмов по жанрам

## Описание проекта

Исследование посвящено сравнению успешности фильмов
различных жанров на основе данных TMDB 5000 Movie Dataset.

В ходе работы проводится исследовательский анализ данных (EDA),
изучаются распределения показателей, строятся визуализации
и формулируются выводы.

## Исследовательские вопросы

- Как различаются жанры по зрительским оценкам?
- Какие жанры имеют более высокие кассовые сборы?
- Как различается отношение сборов к бюджету?
- Насколько устойчивы полученные результаты?

## Структура проекта

- data/ — исходные данные;
- notebooks/ — исследовательский ноутбук;

## Требования

- Python 3.11
- Conda или Miniconda

## Установка и запуск

1. Клонировать репозиторий.
2. Создать окружение:

   conda env create -f environment.yml

3. Активировать окружение:

   conda activate tmdb-eda

4. Запустить Jupyter:

   jupyter lab

5. Открыть:

   notebooks/tmdb_research_eda.ipynb

6. Выполнить ячейки последовательно или использовать Run All.

## Данные

Используется TMDB 5000 Movie Dataset.

Источник:
[Ссылка на датасет](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata)

Исходные CSV размещены в data/.

## Результат

Результатом является исследовательский Jupyter Notebook
с анализом данных, графиками и итоговыми выводами.
